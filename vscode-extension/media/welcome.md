# Welcome to Simba

The Simba extension provides full language support for Simba scripts (`.simba` files):

- **Syntax highlighting** with TextMate grammar
- **Code intelligence** via the Simba Language Server (autocomplete, go-to-definition, hover)
- **Run scripts** directly from VS Code with F5
- **Target window** selection for automation scripts
- **Debug image** visualization panel
- **Snippets** for common patterns and WaspLib templates
