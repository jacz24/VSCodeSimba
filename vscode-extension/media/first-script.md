# Run Your First Script

## Running a Script

1. Open a `.simba` file in the editor
2. Press **F5** or click the **Play** button in the editor title bar
3. Output appears in the **Simba Script Output** panel

## Selecting a Target Window

For automation scripts, select a target window first:

1. Run **Simba: Select Target Window** from the Command Palette (`Ctrl+Shift+P`)
2. Pick a window from the list or enter a handle manually
3. The status bar shows your current target

## Stopping a Script

Press **Shift+F5** or click the **Stop** button to terminate a running script.

## Using Tasks

You can also compile or run scripts via VS Code tasks:

- `Ctrl+Shift+B` to compile the active file
- **Terminal > Run Task > simba** to see available tasks
